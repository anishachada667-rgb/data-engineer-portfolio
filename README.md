# Anisha Reddy Chada — Data Engineer Portfolio

Interactive, responsive portfolio centered on data-engineering architecture.

## Highlights
- Animated data-pipeline background
- Interactive Sources → Ingestion → Processing → Lakehouse → Warehouse → Analytics explorer
- Auto-activating pipeline stages on scroll
- Clickable stage details with tools, engineering focus and measurable impact
- Architecture Lab for batch lakehouse, streaming, governance and AI data pipelines
- Experience, projects, skills, certifications and contact sections
- Responsive mobile layout

## Run
Open `index.html` in a browser, or serve the folder with a static server.

## Publish
Upload to GitHub Pages, Netlify or Vercel.

## Before publishing
Replace the placeholder `resume.pdf` with the real resume PDF.
